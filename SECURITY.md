# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in any Cautera system —
the Cautera platform (`app.cautera.com`), our public websites, or this status
page — please report it privately:

- **Email:** security@cautera.com

Please include enough detail for us to reproduce the issue (affected URL or
component, steps, and impact as you understand it). You should receive an
acknowledgement within **2 business days**.

Please do **not** open a public GitHub issue for security reports, and do not
access, modify, or exfiltrate data that is not yours while demonstrating an
issue.

## Scope of this repository

This repository contains only the configuration and generated history for
Cautera's public status page ([status.cautera.com](https://status.cautera.com),
powered by [Upptime](https://upptime.js.org)). It holds **no customer data and
no platform code**. Findings about the *platform itself* are welcome through
the same email address above — this repository's issue tracker is used by
Upptime automation for uptime incidents only.

## Disclosure

We ask for a reasonable disclosure window to remediate confirmed issues before
any public disclosure, and we will keep you informed of progress. We do not
operate a paid bug-bounty program at this time; we are happy to credit
reporters who wish to be named.

## Supported versions

The status page tracks Upptime upstream; the Cautera platform is a
continuously deployed SaaS — the production version is always the supported
version.
